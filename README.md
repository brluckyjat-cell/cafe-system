# ☕ Chai Ceremony Cafe — Web Application

A premium, fast, production-ready, fully responsive Cafe Ordering & Management Web Application designed specifically for local cafe operations with a **Royal Rajasthani + Modern Premium Cafe** theme.

---

## 🎨 Theme & Styling Palette
- **Cream:** `#F8F3EA` (Main Background)
- **Cream Light:** `#FFFDF9` (Card & Surface Background)
- **Brown:** `#5A3216` (Primary Text & Accents)
- **Coffee:** `#2F1A10` (Navbar, Top Bar & Dark Surfaces)
- **Terracotta:** `#B65A2A` (Action Buttons & Highlights)
- **Gold:** `#C89B3C` (Borders, Icons & Badges)

---

## 🛠️ Tech Stack
- **Frontend:** HTML5, CSS3, Vanilla JavaScript (ES6+ Modules)
- **Backend:** Node.js + Express
- **Database:** Firebase Firestore
- **Authentication:** Firebase Auth / Admin Portal
- **Hosting:** Firebase Hosting / Node.js Engine
- **Design:** Mobile-First Responsive, Soft Shadows, Royal Rajasthani Corner Patterns
